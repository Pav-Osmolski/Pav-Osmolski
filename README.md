## 🚀 Featured Projects

### 🖥️ [AMPBoard](https://github.com/Pav-Osmolski/AMPBoard)

A modern management dashboard for **XAMPP, LAMP and MAMP development environments**, designed as a considerably more capable replacement for the traditional localhost landing page.

Provides project discovery, server and PHP information, live system statistics, configuration utilities, remote access support and a responsive administration interface.

**PHP · JavaScript · MySQL · Apache · Bootstrap · Web development**

---

### 🎵 [DarkOneJSP3](https://github.com/Pav-Osmolski/DarkOneJSP3)

Modern x64 continuation of tedGo's **DarkOne foobar2000 theme**, rebuilt around **Columns UI, JScript Panel 3 and JSplitter**.

The project significantly expands the original theme with enhanced components, extensive customisation, improved layout management, Album Notes, Theme Manager functionality and ongoing compatibility and performance improvements.

**JavaScript · JScript Panel 3 · JSplitter · UI/UX · Audio software**

---

### 🎮 [ReShade Effect Shader Toggler Enhanced](https://github.com/Pav-Osmolski/ReshadeEffectShaderToggler)

An extensively developed version of **REST** for modern **ReShade 6.8+**, providing fine-grained control over where effects are injected into a game's rendering pipeline.

Includes **Direct3D 11 and Vulkan support**, render-target injection, shader grouping, automatic scene-colour detection and support for upscaled rendering paths such as **DLSS**, allowing effects such as AO and RTGI to be placed correctly beneath later fog, post-processing and UI.

**C++ · Direct3D · Vulkan · ReShade API · Graphics programming**
